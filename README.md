## 구성 (15화면)

| 구간 | 내용 |
|---|---|
| **VOCAB** | 교과서 제시 어휘 25개. 카드를 누르면 뒤집히고, 옆 패널에 뜻·품사·본문 예문이 표시됩니다. 카드마다 교과서 쪽·줄 번호(`p.61 ℓ.9`)가 붙어 있습니다. |
| **READ 1–12** | 본문을 3~5문장씩 나눈 읽기 화면. 문장 아래에 흐린 회색 해석이 깔립니다. |
| **POINT 1** | 복합관계대명사 `whatever · whichever · whoever` — 설명, 표, 예문, 본문에서 찾기, 배열 연습 4문항 |
| **POINT 2** | `not A but B` — 설명, 표, 예문, 본문에서 찾기, 어법 선택 연습 4문항 |

### 화면에서 쓸 수 있는 것

- **어법·표현 카드** — 본문의 파란 낱말(어법)·초록 낱말(주요 표현)을 누르면 아래에 설명 카드가 열립니다. 다시 누르면 닫힙니다.
- **필기** — 하단 `PEN`에서 4색 펜과 지우개. 화면마다 따로 저장되고, 창을 닫으면 지워집니다.
- **이동** — `HOME` / `PREV` / `NEXT`, 좌우 방향키, 상단 탭.
- **연습 문제** — 배열 문제는 순서대로 눌러 맞추고(틀리면 되돌아감), 선택 문제는 정답을 고르면 빈칸이 채워지며 이유가 열립니다. 푼 기록은 브라우저에 저장됩니다.
